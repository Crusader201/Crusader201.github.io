Search for a GitHub username to see its profile and up to five recently updated public repositories. Use the copy button to share the profile link, and use the dark-mode button to switch themes. GitHub's unauthenticated API rate limits apply; the page displays an error if the limit is reached.

To preview locally, run `python3 -m http.server` in this directory and open `http://localhost:8000/home.html`. Clipboard access requires a secure context such as HTTPS or localhost.
